
# Library Management System

## Project Overview

A simple menu driven Library Management System developed
using Python and Object-Oriented Programming principles.

## Project Structure

mini_project/
- main.py
- book.py
- library.py
- member.py
- README.md

## Features

- Add and remove books.
- Display all available library books.
- Search books using ISBN.
- Register student and teacher members.
- Borrow and return books.
- Prevent borrowing unavailable books.
- Enforce different borrowing limits for member types.

## OOP Concepts Demonstrated

- Classes and Objects
- Constructors and Instance Methods
- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding
- super()
- Composition

## Borrowing Limits

| Member Type | Borrowing Limit |
|---|---|
| Student | 2 books |
| Teacher | 5 books |

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python main.py

## Technologies Used

- Python 3
- Object-Oriented Programming
